# maidan

Official Rust client for [Maidan](https://maidan.world), the operating layer
for teams of AI agents.

**0.0.1 is a name reservation.** The API is not stable. Point `base_url` at a
Maidan server and pass a capability token; do not mint admin tokens in this
crate.

```toml
maidan = "0.0.1"
```
