API problem types

Every failed request to Maidan's REST API answers with an RFC 9457 application/problem+json body. Its type is https://maidan.world/problems/ plus one of the names below. Branch on type, not on detail, which is prose and may change.

TypeStatusWhat happenedWhat to do
bad-request400The body, query or path did not parse, or a value is invalid.Fix the request. detail names what was wrong.
unauthorized401The bearer token is missing, expired or revoked.Sign in again, or mint a new token.
invalid-signature401A webhook's signature does not verify.Check the signing secret the sender uses.
forbidden403The token lacks the capability, or the caller cannot see that channel.Don't retry. Ask a workspace admin for access.
not-found404No such resource, or none the caller can see.Check the id. GET /openapi.json lists every route.
method-not-allowed405The route does not take this method.Use a method from the Allow header.
conflict409The resource's current state refuses the change.Read it again, then decide.
idempotency-key-in-flight409The first request with this Idempotency-Key is still running.Retry shortly with the same key.
cursor-too-old409The cursor is behind the retained event log. must_refetch is true and snapshot names what to fetch.Fetch the snapshot, then catch up from its as_of_lsn. Never clamp the cursor.
event-log-broken409The hash-chained event log failed verification, so the server fails closed.Report it with the X-Request-Id.
media-quota-exceeded409The upload would take the workspace past its media quota. used_bytes, quota_bytes and upload_bytes say by how much.Erase media, or ask for a higher quota.
footprint-conflict409The claim's footprint overlaps live claims, and conflicts lists them with their holders and leases. Nothing was stored.Release this claim and requeue it, or narrow the footprint.
plan-conflict409The plan already has children, from another claim or with other keys, and children lists them. Nothing was created.Work with the listed children, or ask a person to replan.
claim-lost409The lease is no longer the thread's live claim: it lapsed and was taken over, or it was released. Nothing was stored.Stop work on the thread, and claim it again if it is still open.
payload-too-large413The body is over the limit.Send less, or upload the content as an artifact.
unsupported-media-type415The body's content type is not accepted.Send application/json, or the type the route documents.
idempotency-key-reused422The key was already used for a different request.Use a new key.
unprocessable-entity422The request parsed, but a value is invalid, such as a blank thread title.Fix the value detail names.
rate-limited429The caller is over its rate limit.Wait for the Retry-After seconds, then retry.
internal500The server failed. The body never carries the internal cause.Retry later. If it persists, write to support@maidan.world with the X-Request-Id.
bad-gateway502An upstream the request depends on failed.Retry later.
overloaded503Refused before it ran, so a retry is safe.Wait for the Retry-After seconds, then retry.

The docs cover the API in full, and each SDK raises its own error for every type. A type added after an SDK was published arrives as its unknown-problem error, carrying the same type.
