## Traps that cost me time

These are not in `CLAUDE.md` because they are about *method*, not this codebase.

**A check that shares its subject's blind spot reports success.** #921 removed
2,254 cluster citations and I verified zero remained with a line-based `grep`.
Fifty survived — the ones that had wrapped across a line break, which no single
line matches. #929 fixed it. I then made the same class of error twice more in
one session. If you sweep with a line-oriented tool, verify with one that is
not.

**CI being green says only that CI's path works.** The quickstart health check
(#931) was broken for hours with all 17 checks passing, because
`docker compose smoke` exercises `compose.yaml` — built from this tree — while
the quickstart runs a *released* binary. The question is not "does this work?"
but "what is different about the place it runs?"

**Run the documented path, do not read it.** #931 was found by trying to record
the README's own quickstart for a GIF. Four earlier recordings were discarded;
one of them because I had written `printf` lines to fake the setup output, which
is the exact thing a recording exists to not do.

**Verify a fix against the broken code.** Every guard added this session was
checked by restoring the defect and watching it fail with the right message.
Two of them passed vacuously before that check.

**Read the output of backgrounded commands.** `cargo … | tail -n` exits with
`tail`'s status, so `&& echo OK` prints OK on a failed build. I did this and
reported a clean lint that was not.

## Repo-specific things worth knowing

- **Two clippy passes.** `--all-targets -- -D warnings` does *not* enable
  restriction lints; CI runs a separate `-D clippy::unwrap_used
  -D clippy::expect_used` over library code. A PR here has failed on the second
  alone.
- **`mdbook` is not one of the 8 required checks** and goes red unnoticed. It
  fails on any dead internal link — which makes it the thing that catches a docs
  change that moved a page. Run `bash book/sync-docs.sh && (cd book && mdbook
  build)` before merging docs.
- **Three new contract tests exist now.** `docs_numbers_contract` ties the MCP
  tool count, the crate count and the README image pin to their sources;
  `migration_register` ties the migration files to the register. If one fails,
  the doc or the register is wrong — not the test.
- **`git add -A` sweeps the untracked research corpora** in the repo root. Both
  are gitignored now, but the habit has cost a revert.
- **The external audit corpora** (`maidan-audit-corpus/`,
  `maidan-docs-audit-corpus/`) are on disk, gitignored, and worth reading before
  re-deriving a finding.
