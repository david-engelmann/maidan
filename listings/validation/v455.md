## maidan.world

## Protocol-layer properties and trust model

Unchanged since `v441.0.0`, held by the same tests: nobody accepts their own
approval request; a gate is accepted only by a signed-in person's session or
`approval:grant`; the close gate is a durable store row that an elicited
client answer never decides. Provider-rendered approval UI is untrusted
display, the Maidan console is the trust root, and an approval whose evidence
the human did not see in the console is provisional.
