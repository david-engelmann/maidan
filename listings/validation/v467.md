## What passed

- `initialize` negotiation for every supported revision. A client that asks
  for an unknown revision is offered the newest.
- The Inspector against `/mcp/streamable`, `/mcp`, `/mcp/worker`,
  `/mcp/reviewer` and `/mcp/coordinator`:
  - `tools/list` returns the catalog, or exactly the profile's tools, and the
    SDK accepts every schema;
  - `whoami` authenticates as the bearer;
  - resources and prompts answer.
- One valid and one invalid call per tool group, on `/mcp/streamable`.
- **Every tool, called validly:**
  - each profile tool on its own endpoint;
  - the coordinator's tools on a token that holds only the eight capabilities
    an OAuth grant can carry;
  - every other write on `/mcp/streamable`;
  - every read-only tool on `/mcp/streamable`.
- **Every tool, called badly:** all 265 refused, each naming the argument it
  got wrong. Every successful call carries MCP `content`.
- **The six that need a backend beyond the store succeeded for real:**
  - the four multipart artifact tools against MinIO, with the bytes read back
    by sha256;
  - `top_up_credits`, which opened an intent configured for Base Sepolia; the
    chain's RPC was the local stub, so no call reached a real chain;
  - `advise_land_gate`, which got a recommendation from a local stub of its
    advisor API.
