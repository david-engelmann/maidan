### Added
- Task fingerprints (Context Economics C8a): every new thread with a brief, from any creation path (plain create, create with attributes, plan children including review children, recipe threads), stores a versioned SHA-256 fingerprint of its title, description and task inputs, linked to the oldest open or in-review identical task in the same workspace. Claimed tasks are still open, so in-flight work is a duplicate target; closed tasks and other workspaces never are. Imported history is not fingerprinted. Read it with `GET /threads/{id}/fingerprint`; `duplicate_of` is hidden when the caller cannot see the original. Migration 0204. The link is advisory: reuse offers and claim refusal follow in C8b.
