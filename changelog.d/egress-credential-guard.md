### Maidan refuses to deliver a result that holds a credential

- **Security:** before every send to GitHub, Slack or Linear, and before the change flow writes a commit or a pull request, Maidan scans the text it would publish for credential shapes: GitHub tokens, Anthropic and OpenAI-style keys, AWS access key ids, Slack tokens, JSON Web Tokens, PEM private keys and its own `maid_` secrets. A match refuses the send with nothing published, so a producer prompt-injected by what it reviewed cannot leak a key through Maidan. The delivery row is `skipped` with a reason that names the kind and the surface, never the text; the same goes to the log, `maidan_egress_credential_refused_total{surface,kind}` and the operator channel. `MAIDAN_EGRESS_CREDENTIAL_GUARD=off` turns it off.
